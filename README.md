# 📄 PDFScriptor

**PDFScriptor** is a user-friendly web application built with [Streamlit](https://streamlit.io/) that allows users to create custom PDF documents with ease. It lets you define the title, author, chapters, and even add a cover image. Perfect for generating reports, notes, or personalized documents on the fly.

---

## 🚀 Features

- 🎨 Simple and intuitive web interface.
- 📝 Customizable document title, author, and multiple chapters.
- 🖼️ Optional cover image upload.
- 🔠 Font and font size selection per chapter.
- 📥 Instant download of the generated PDF.

---

## 🛠️ Technologies Used

- [Python](https://www.python.org/)
- [Streamlit](https://streamlit.io/) – For the web interface.
- [FPDF](https://pyfpdf.github.io/fpdf2/) – For PDF creation.

---

## 🚀 Usage
1. Clone this repository.

2. Install the required dependencies:
   pip install streamlit fpdf
   
3. Run the application with Streamlit:
   streamlit run app.py

4. Fill in the document details in the browser interface:
   - Enter the Document Title and Author Name.
   - Optionally, upload an image for the cover.
   - Define the number of chapters and provide details for each one:
      - Chapter title
      - Chapter body text
      - Font style and size
5. Click Generate PDF to create the document.
6. Once generated, click Download PDF to save the file to your computer.
